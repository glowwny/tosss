# Safari 열린 링크 정리

휴대폰 Safari에 열려 있던 탭을 주제별로 정리한 폴더입니다.
기존 `tosss` 파일(`dist/`, 폰트 자산)과 섞이지 않게 이 폴더 안에서만 작업합니다.

## 구성
- `index.html`: 주제별로 정리한 페이지 (검색, 카테고리 필터, 확인 체크)

## 정리 기준
- 광고 추적값(utm_*, fbclid, gclid 등)을 지우고, 같은 페이지는 하나로 합쳤습니다.
- 결제, 본인인증, 주문 완료, 사내 링크처럼 개인 정보가 들어갈 수 있는 탭은 링크 없이 이름만 남겼습니다.
- 원본 링크 목록은 이 저장소가 공개 저장소라서 올리지 않았습니다.
